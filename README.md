This project analyzes a year-long sales dataset for an e-commerce store to uncover insights into product popularity and regional preferences.

## Objectives
- Identify the most popular product categories.
- Analyze regional sales preferences.

- ## Tools Used
- Microsoft Excel
- PDF report

- ## Key Insights
- Home Goods is the most popular category overall.
- Regional preferences vary, e.g., South prefers Sports and Home Goods.
- Different zones require tailored marketing strategies.
